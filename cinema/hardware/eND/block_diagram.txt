SOFTWARE / HARDWARE INTERACTION MAP
──────────────────────────────────────────────────────────────────────────

  ANDROID USERSPACE
  ┌──────────────────────────────────────────────────────────┐
  │  Cinema App                                              │
  │  ├─ ND setpoint UI (manual / exposure-hold / DOF-hold)  │
  │  ├─ Camera2 AE integration (metered EV → ND delta cmd)  │
  │  ├─ MCU telemetry display (T°, Vrms, current ND)        │
  │  └─ writes persist.cinema.nd_enable → triggers init.rc  │
  └───────────────────────┬──────────────────────────────────┘
                          │ Binder / property service
  ┌───────────────────────▼──────────────────────────────────┐
  │  ANDROID INIT (init.cinema.rc)                           │
  │  on property:persist.cinema.nd_enable=1                  │
  │  ├─ write /sys/kernel/cinema_mode/enable 1               │
  │  ├─ start cinema_on_apply (ZRAM 4→2 GB)                  │
  │  ├─ wbt_lat_usec, force_no_nap, cpuset, uclamp tuning    │
  │  └─ write thermal_message/cinema_mode 1                  │
  └───────────────────────┬──────────────────────────────────┘
                          │
  ┌───────────────────────▼──────────────────────────────────┐
  │  KERNEL (cinema_mode.c driver)                           │
  │  ├─ freq_qos floor (all clusters pinned to max)          │
  │  ├─ cpu_latency_qos 100 µs (blocks deep C-states)        │
  │  ├─ wakeup_source (prevents suspend during shoot)        │
  │  └─ cpufreq notifier (hotplug resilience)                │
  └──────────────────────────────────────────────────────────┘

  eND HARDWARE PATH  (parallel, independent from SW perf stack)
  ┌──────────────────────────────────────────────────────────┐
  │  Cinema App ──USB/UART──► eND MCU ──LC drive──► cell     │
  │                                                          │
  │  Data flow:                                              │
  │  AE metered EV ──► ND delta ──► setpoint cmd ──► MCU    │
  │  MCU ──► LUT[setpoint, T°] ──► Vrms ──► DAC ──► cell   │
  │  Cell T° ──► TMP117 ──► MCU ──► telemetry ──► App       │
  └──────────────────────────────────────────────────────────┘
